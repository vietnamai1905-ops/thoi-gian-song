# THỜI GIAN SỐNG — V4 AVANT

## Ý tưởng
Bản V4 tập trung vào 3 thứ quan trọng nhất:
1. Hôm nay còn lại bao nhiêu thời gian
2. Phần đời còn lại bao nhiêu năm / tháng
3. Trong vùng tuổi sung mãn nhất (Vàng + Bạc), còn lại bao nhiêu

## Công nghệ
- HTML / CSS / JS thuần
- Chạy trực tiếp trên GitHub Pages
- Dữ liệu lưu bằng localStorage
