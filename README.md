# THỜI GIAN SỐNG — V3 PREMIUM

## Điểm mới của V3
- Phong cách giao diện premium hơn: kính mờ, chữ thanh, layout thoáng.
- Trọng tâm là **thời gian thật sự còn có thể tận hưởng**.
- Có **số tuần**, bỏ **giây**.
- Có phần **Vàng / Bạc / Đồng / Gỗ** rõ ràng.
- Có panel **mốc sung mãn còn lại**.
- Dùng **HTML/CSS/JS thuần**, chạy trực tiếp trên GitHub Pages.
- Dữ liệu lưu bằng **localStorage** trên trình duyệt.

## File cần đưa lên GitHub
- index.html
- style.css
- app.js
- background.jpg

## Cách triển khai GitHub Pages
1. Tạo repo mới hoặc mở repo hiện có.
2. Upload 4 file trên lên nhánh main.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch.
5. Chọn nhánh main và thư mục /root.
6. Save.

## Thay ảnh nền
Giữ nguyên tên file `background.jpg`, chỉ thay nội dung ảnh.
